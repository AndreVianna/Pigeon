# Pigeon beta invitation

Use this text after the `v0.7.0-beta.1` prerelease and its tagged test guide are public.

---

**Help test Pigeon on macOS and Linux**

Pigeon is a free, open-source CLI and plugin that lets two AI agent sessions exchange messages without copying text between them. We have exercised Claude and Codex conversations on Windows. The macOS and Linux builds pass automated checks, but we need people on those systems to try the real agent workflow and tell us what happens.

Download [Pigeon 0.7.0-beta.1](https://github.com/AndreVianna/Pigeon/releases/tag/v0.7.0-beta.1), follow the [beta test guide](https://github.com/AndreVianna/Pigeon/blob/v0.7.0-beta.1/docs/beta-testing.md), and [post a beta report issue](https://github.com/AndreVianna/Pigeon/issues/new?template=beta-report.yml). A failed install, a message that arrived only after polling, or a partial test is just as useful as a complete two-way conversation.

Please use disposable conversations and made-up messages. The local service does not authenticate callers, and the Windows and macOS installers are unsigned. Network sharing is optional; test it only on a trusted private network and a single-user machine. The guide lists the current limits and what to include in a public issue.

We are especially interested in Apple Silicon and Intel Macs, Ubuntu/Debian on x64 and ARM64, and RPM-based distributions. Please include your operating system, processor, agent app and version in the report.
